## 利用方法

### 大まかな流れ
ダミーで用意した３店舗から、予約したい店舗を選択し、座席と日時を指定して予約します。

### 詳細な流れ
ログイン後、トップ画面から予約したい店舗を選択し、座席選択の間取り図画面へ遷移します。
間取り図が表示されるので、予約したい座席を選択し、「選択した席で予約を進める」をクリックします。
予約フォーム画面へ遷移するので、そこで予約人数と電話番号を入力します。その際、予約日時は自動で入力された状態になっています。
入力後「予約確認画面へ進む」をクリックし、予約確認画面へ遷移します。
入力された情報に間違いなければ、「予約を確定する」をクリックし、予約完了画面へ遷移します。
予約完了画面からは、トップ画面に戻るか、予約履歴一覧画面へ遷移できます。

予約履歴一覧画面に進むと、予約状況が確認できます。また、一覧の「間取り図」をクリックすると、予約履歴の詳細画面へ遷移します。
詳細画面からは、予約した内容と選択した座席を確認できます。
画面下部には、「予約のキャンセル」が最初からあり、予約日時の15分前になると「チェックイン」ボタンが現れます。
今回は、予約日時から15分経過すると自動キャンセルされますが、その前にチェックインすると、「退店する」ボタンが現れます。
「退店する」をクリックすると、予約データが消えて、その座席は再び予約できるようになります。

## アプリケーションを作成した背景

来店してから混雑している店内で、空席を探して妥協できそうな空間を探すことにストレスを感じる人向け。
「空いてる席にお座りください」で、そこから探すことがストレスな人向け。
来店前に予め混雑状況を把握した上で、妥協できる座席を予約することで、ストレスなく喫茶店での時間を楽しめるようにするため。
また、混雑状況を店舗側も視覚的に把握できるようにするため。

## 工夫したポイント

### 制作背景
喫茶店で勉強する際、混雑している店内で空席を探すストレスがあった。
来店する前に空席を予約しておくことで、探す手間を省きたいと思った。

### 使用技術
- 店内間取り図を用意。座りたい座席のラジオボタン（value属性に座席番号をあらかじめ埋め込み）を選択すると、JavaScriptでchecked状態のvalueを取得し、予約の際にURLに乗せて画面遷移する形にした。
- 予約状況は、enumを用意して「予約済み」または「利用中」の状態を管理する形にした。
- 予約完了後、予約済みの座席は前後３時間は予約できないようコントローラー側でデータ取得を設定した。そうすることで、３時間前後の予約済みの座席にグレイアウトをつけ選択できないようにし、予約の重複を防いでいる（３時間制の利用ルール）。
- 予約日時になってから15分経過すると自動で予約がキャンセルされるようにして、予約の放置と店舗側の損失を防いでいる。
- 自動キャンセルしたら、予約したユーザーにメールでその旨を通知するようにしている。

### 開発方法
- 最初に、アプリの全体像を把握するために、ER図と画面遷移図を作成した。
- DB設計を行い、モデルを作成してから、コントローラーとビューを作成する形で開発を進めた。
- DB設計については調整が前後したけれども、予約システムとしての要件を最低限満たす形で整えた。
- 予約の重複を防ぐためのロジックや、予約の自動キャンセルのロジックは、実装していく中で足りない要件や見落としがあった際に都度追加していった。

### タスク管理
- 進捗管理用に専用のテキストファイルを用意し、タスクを優先順位付きで書き出して管理した。
- 基本的には画面遷移図を見ながら、画面ごとに必要な実装を整理し、予約フローの流れに沿って順に着手した。
- 実装中に新たに見つかった課題（重複バリデーションの不足や、画面遷移時のバグなど）もその都度書き加え、対応漏れを防いだ。

### なぜ間取り図画面と予約フォームを一緒にしなかったのか
間取り図を選択できることを、登録していないユーザーでもそれだけ見れるようにしておきたかったから。
設計当初も一緒にしようか迷いましたが、あえて棲み分けをし、空席状況と間取り図で選択できる使い勝手の良さを体験させ、使いたかったら新規登録・ログインして利用してもらおうという判断をしました。そのため、予約フォーム以降はログインしていないと使えないようにしております。

（補足：初のオリジナルアプリの実装で、制作する際に読みやすいようにしたかったという理由もあります。）

|-------------------|----------|--------------------|----------------------|

| encrypted_password | string   | NOT NULL           | パスワード（暗号化） 　　|
| created_at        | datetime | NOT NULL           |                      |
| updated_at        | datetime | NOT NULL           |                      |

---

### seats（席）

| カラム名    　 　 | 型        | 制約               | 説明          　 |
|-----------------|-----------|--------------------|----------------|
| id          　  | bigint    | PK                 |                |

| updated_at      | datetime  | NOT NULL           |                  |

| カラム名     　| 型       | 制約          | 説明                     　  |

| id           | bigint   | PK            |                            |
