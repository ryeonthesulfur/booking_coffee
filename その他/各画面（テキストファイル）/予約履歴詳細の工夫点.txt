      <% if @reservation.notes.present? %>
        <div class="reservation-detail__row">
          <span class="reservation-detail__label">備考</span>
          <span class="reservation-detail__value"><%= @reservation.notes %></span>
        </div>
      <% end %>


「.present?」メソッドについて
マイグレイトする際に備考カラムは、null でもいいようにしたので、ユーザーが記入していた場合はその都度、DBから取得して来れる形にいたしました。
これによって、記入がない場合は何も表示されず、記入がある場合には表示するという場合分けを実現しています。

<%# 各店舗の間取り図を表示する部分。予約確認の間取り図と同様に、予約席番号を data-seat-number 属性にセットして、該当席を選択した状態で表示する。%>
    <div class="confirm-seat-container">
      <div id="confirmed-seat" data-seat-number="<%= @seat.seat_number %>"></div>
      <% if @store.name == "蔵前喫茶店" %>
        <%= render "stores/kuramae_floor", confirm_mode: true %>
      <% elsif @store.name == "カフェ・ロンド" %>
        <%= render "stores/rondo_floor", confirm_mode: true %>
      <% elsif @store.name == "喫茶むすび" %>
        <%= render "stores/musubi_floor", confirm_mode: true %>
      <% end %>
    </div>


ここは予約確認画面と同じ仕組みで、JSファイルの「reservation_confirm.js」が「data-seat-number」を読み取る。
    →「.seatNumber」でdatasetオブジェクトの持つseatNumberという値を取り出すためにプロパティへアクセスする。

    const seatNumber = selectedSeat.dataset.seatNumber;


そして「seatNumber」という const 型の変数に選択した座席を詰め込む。
全座席分のデータを取得し、「radios」に変数を詰め込む。そこから全ての座席を無効化した後、一つずつ座席を照らし合わせて、選択した座席と合致したら、
それだけCSSの選択済の状態を true にする。

    <%# 予約キャンセル・チェックイン・退店などのアクションボタンの部分をレンダリング %>
    <%= render "reservation_actions", reservation: @reservation %>  

予約詳細画面の下部から予約キャンセル・チェックイン・退店のボタン状況に応じて表示切り返されるようにするため、
予約履歴一覧と同様、enumを用いて条件分岐しました。

また、コードの区別がつきやすいように、あえて部分パーシャルにその部分だけ分けました。

enum において設定した「1 = using」（利用中）を表す状態の時は、退店ボタンが出現するようにし、
予約日時の15分前になったら、チェックインと予約キャンセルボタンの両方が表示されるようにし、
それ以外の時は、常に予約キャンセルボタンが出るようにしました。
