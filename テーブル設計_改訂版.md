# booking_coffee

喫茶店の席予約システム

---

## テーブル設計

### users（ユーザー）

| カラム名            | 型       | 制約               | 説明                  |
|---------------------|----------|--------------------|----------------------|
| id                  | bigint   | PK                 |                      |
| name                | string   | NOT NULL           | 氏名                  |
| email               | string   | NOT NULL, UNIQUE   | メールアドレス          |
| encrypted_password  | string   | NOT NULL           | パスワード（暗号化）    |
| created_at          | datetime | NOT NULL           |                      |
| updated_at          | datetime | NOT NULL           |                      |

---

### stores（店舗）※新規

| カラム名    | 型       | 制約     | 説明                         |
|-------------|----------|----------|------------------------------|
| id          | bigint   | PK       |                              |
| name        | string   | NOT NULL | 店舗名                        |
| image_url   | string   | NOT NULL | カード表示用の画像URL          |
| smoking     | boolean  | NOT NULL | 喫煙可 = true / 禁煙 = false  |
| created_at  | datetime | NOT NULL |                              |
| updated_at  | datetime | NOT NULL |                              |

---

### seats（席）※変更

| カラム名        | 型       | 制約          | 説明                        |
|-----------------|----------|---------------|-----------------------------|
| id              | bigint   | PK            |                             |
| store_id        | bigint   | FK, NOT NULL  | どの店舗の席か               |
| seat_number     | string   | NOT NULL      | 席番号（テラス1、窓辺3 など） |
| seat_type       | string   | NOT NULL      | カウンター席・テーブル席など  |
| capacity        | integer  | NOT NULL      | 最大収容人数                 |
| price_per_hour  | integer  | NOT NULL      | 1時間あたりの料金             |
| created_at      | datetime | NOT NULL      |                             |
| updated_at      | datetime | NOT NULL      |                             |

---

### reservations（予約）※変更

店舗名・席番号・席の種類・禁煙喫煙は seat_id を通じてアソシエーションで取得するため、
reservations テーブルへの直接追加は不要。

| カラム名      | 型       | 制約          | 説明            |
|---------------|----------|---------------|-----------------|
| id            | bigint   | PK            |                 |
| user_id       | bigint   | FK, NOT NULL  | どの客か         |
| seat_id       | bigint   | FK, NOT NULL  | どの席か         |
| start_time    | datetime | NOT NULL      | 予約日時         |
| num_people    | integer  | NOT NULL      | 人数             |
| phone_number  | string   | NOT NULL      | 連絡先電話番号   |
| notes         | text     |               | 備考（任意）     |
| created_at    | datetime | NOT NULL      |                 |
| updated_at    | datetime | NOT NULL      |                 |

---

## リレーション

- User has many Reservations
- Store has many Seats
- Seat belongs to Store
- Seat has many Reservations
- Reservation belongs to User
- Reservation belongs to Seat

---

## 画面遷移とコントローラーの対応

| 画面                          | アクション              | 内容                          |
|-------------------------------|------------------------|-------------------------------|
| トップ（店舗カード一覧）        | stores#index           | 店舗カード一覧（カルーセル）    |
| 店舗詳細 + 間取り図（席選択）   | stores#show            | 店舗情報 + 席の見取り図        |
| 予約フォーム                   | seats#show             | 席詳細 + 予約入力フォーム      |
| 確認画面                       | reservations#confirm   | 入力内容の確認・修正           |
| 予約完了                       | reservations#create    | 予約レコード作成               |
| 予約履歴一覧                   | reservations#index     | ユーザーの予約一覧             |
| 予約詳細                       | reservations#show      | 予約の詳細表示                 |
| キャンセル（削除）              | reservations#destroy   | 予約レコード削除               |

---

## アソシエーションを通じたデータ取得例

```ruby
reservation.seat.seat_number   # 席番号（テラス1 など）
reservation.seat.seat_type     # 席の種類（テラス席 など）
reservation.seat.store.name    # 店舗名
reservation.seat.store.smoking # 喫煙可否
```
