# 解説：`f.select` (動的なドロップダウンメニューの作り方) 260906

このドキュメントは、Railsのフォームヘルパー `f.select` を使って、状況に応じて選択肢が変わるドロップダウンメニューを作成する方法について、世界一分かりやすく解説します。

```erb
<%= f.select :num_people,
      (1..@seat.capacity).map { |n| ["#{n}名", n] },
      { prompt: "人数を選択" },
      class: "form-input" %>
```

---

## 結論

これは、**「この席の定員（`@seat.capacity`）を上限として、1名から定員までの人数の選択肢を持つドロップダウンメニューを作りなさい」** という命令です。

---

## コードの分解ショー

このコードは、`f.select` メソッドに4つの「引数（ひきすう）」を渡しています。

### 1. `f.select`
-   `f` は `form_with` によって作られた「フォームビルダー」です。
-   `.select` は、HTMLの `<select>` タグ（ドロップダウンメニュー）を生成するためのメソッドです。

### 2. 第1引数: `:num_people`
-   **「どのデータを保存するか」** を指定します。
-   ここで選択された値は、フォーム送信時に `@reservation` オブジェクトの `num_people` という属性に保存されます。

### 3. 第2引数: `(1..@seat.capacity).map { ... }`
-   **「どんな選択肢を作るか」** を指定します。ここが一番のキモです。
-   `@seat.capacity` には、その席の定員（例えば `4`）が入っています。
-   `(1..4)` は、Rubyで「1から4までの連続した数字」を意味します。
-   `.map { |n| ["#{n}名", n] }` は、その数字を一つずつ加工する命令です。
    -   `n` が `1` の時 → `["1名", 1]` というペアを作る
    -   `n` が `2` の時 → `["2名", 2]` というペアを作る
    -   ...
-   結果として、`[["1名", 1], ["2名", 2], ["3名", 3], ["4名", 4]]` というリストが完成します。
-   `f.select` はこのリストを受け取り、**1つ目の要素（"1名"など）をユーザーに見える選択肢**として、**2つ目の要素（1など）を実際に送信される値**として使います。

### 4. 第3引数: `{ prompt: "人数を選択" }`
-   **「初期状態の表示」** を指定するオプションです。
-   `prompt:` を指定すると、ドロップダウンの先頭に、選択できない案内用の選択肢（この場合は "人数を選択"）が表示されます。これにより、ユーザーに選択を促すことができます。

### 5. 第4引数: `class: "form-input"`
-   **「見た目（CSS）」** を指定するオプションです。
-   生成されるHTMLの `<select>` タグに `class="form-input"` という属性を追加し、CSSでデザインを適用できるようにします。

## 最終的なHTML（例）

もし `@seat.capacity` が `2` だった場合、このERBコードは最終的に以下のようなHTMLを生成します。

```html
<select class="form-input" name="reservation[num_people]" id="reservation_num_people">
  <option value="">人数を選択</option>
  <option value="1">1名</option>
  <option value="2">2名</option>
</select>
```

このように、RailsのヘルパーとRubyのメソッドを組み合わせることで、データに応じて柔軟に変化するHTMLを、非常に短く分かりやすく書くことができるのです。
