# 間取り図の日時選択〜リロードの全体フロー

---

## 全体の流れ（概要）

```
① ページ読み込み（turbo:load）
        ↓
② seats_index.js が date-input に flatpickr を取り付ける
        ↓
③ ユーザーがカレンダーで日時を選択する
        ↓
④ onChange が発火 → minTime を更新
        ↓
⑤ カレンダーを閉じる
        ↓
⑥ onClose が発火 → URLに ?start_time= を付けてリロード
        ↓
⑦ ブラウザが ?start_time= 付きのURLでリクエストを送る
        ↓
⑧ StoresController#show が start_time を受け取りDBを検索
        ↓
⑨ ページが再描画される（flatpickrの復元 + グレイアウト反映）
```

---

## ① ページ読み込み（turbo:load）

間取り図ページ（`stores#show`）を開くと `turbo:load` イベントが発火し、`seats_index.js` が動き出す。

---

## ② seats_index.js が flatpickr を取り付ける

```javascript
const dateInput = document.getElementById('date-input');  // 間取り図ページのID

flatpickr(dateInput, {
  defaultDate: defaultDateVal,  // URLにstart_timeがあれば復元、なければ次の30分スロット
  ...
});
```

---

## ③ ユーザーがカレンダーで日時を選択する

例：`2026-09-06 15:00` を選ぶ。

---

## ④ onChange が発火 → minTime を更新

日付を変えるたびに `onChange` が動き、「今日かどうか」を判定して選べる最小時刻を更新する。

```javascript
onChange: function (selectedDates, dateStr, instance) {
  const isToday = selected.toDateString() === new Date().toDateString();
  instance.set('minTime', isToday ? getNextHalfHourString() : '00:00');
  // 今日 → 現在時刻以降のみ選択可能
  // 翌日以降 → 00:00 から選択可能
}
```

---

## ⑤ カレンダーを閉じる

ユーザーが時刻まで選んでカレンダーを閉じる（または時刻をクリックすると自動で閉じる）。

---

## ⑥ onClose が発火 → URLを更新してリロード

```javascript
onClose: function (selectedDates, dateStr, instance) {
  // '.floor-map-container' が存在する = 間取り図ページ のときだけ実行
  if (document.querySelector('.floor-map-container')) {
    const url = new URL(window.location.href);
    url.searchParams.set('start_time', dateStr);  // URLに ?start_time=2026-09-06 15:00〜 を付ける
    window.location.href = url.toString();          // ← ページリロード
  }
}
```

遷移するURL：

```
/stores/1?start_time=2026-09-06+15%3A00%E3%80%9C
```

---

## ⑦ ブラウザがリクエストを送る

ブラウザが `?start_time=2026-09-06 15:00〜` 付きのURLで `stores#show` にGETリクエストを送る。

---

## ⑧ StoresController#show が start_time を受け取りDBを検索

```ruby
start_time = Time.zone.parse(params[:start_time].delete("〜"))
# → "2026-09-06 15:00〜" から「〜」を除いてTimeオブジェクトに変換

@reserved_seat_numbers = @store.seats
  .joins(:reservations)
  .where(reservations: { status: [:reserved, :using] })
  .where("reservations.start_time > ? AND reservations.start_time < ?",
         start_time - 3.hours,   # → 12:00
         start_time + 3.hours)   # → 18:00
  .pluck(:seat_number)
# → ["A-1", "B-3"] のように、その時間帯に利用中になる座席番号の配列が入る
```

`@reserved_seat_numbers` に「その時間帯に予約が入っている座席番号の一覧」が入る。

---

## ⑨ ページが再描画される

### flatpickrの復元

リロード後も `seats_index.js` が再び動き、URLの `?start_time=` を読んで flatpickr の初期値を復元する。

```javascript
const startTimeParam = urlParams.get('start_time');  // "2026-09-06 15:00〜"
defaultDateVal = new Date(startTimeParam.replace('〜', ''));
// → flatpickrのカレンダーに 2026-09-06 15:00 が表示される
```

### グレイアウトの反映

間取り図パーシャルが `@reserved_seat_numbers` を参照して、予約済み座席に `disabled` を付与する。

```erb
<% if @reserved_seat_numbers.include?(seat.seat_number) %>
  <%# この座席はグレイアウト（選択不可） %>
<% end %>
```

---

## まとめ

| ステップ | 担当 | やっていること |
|---|---|---|
| ① | ブラウザ / Turbo | turbo:load イベントを発火 |
| ② | `seats_index.js` | date-input にflatpickrを取り付け |
| ③ | ユーザー | カレンダーで日時を選択 |
| ④ | `onChange`（seats_index.js） | 選択した日付に応じて minTime を更新 |
| ⑤ | ユーザー | カレンダーを閉じる |
| ⑥ | `onClose`（seats_index.js） | URLに ?start_time= を付けてリロード |
| ⑦ | ブラウザ | ?start_time= 付きのGETリクエストをRailsに送る |
| ⑧ | `StoresController#show` | start_time を受け取り、前後3時間で予約済み座席を検索 |
| ⑨ | `seats_index.js` + ビュー | flatpickrを復元 + 予約済み座席をグレイアウト表示 |

**リロードを使うことで、「日時選択」と「グレイアウト更新」をサーバーサイドのDBアクセスと連携させている。**
