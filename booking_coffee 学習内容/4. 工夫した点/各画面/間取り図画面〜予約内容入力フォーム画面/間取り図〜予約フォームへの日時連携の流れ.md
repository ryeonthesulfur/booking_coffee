# 間取り図〜予約フォームへの日時連携の流れ

---

## 全体の流れ（概要）

```
① 間取り図ページで日時を選択（flatpickr）
        ↓
② 「予約する」ボタンを押す（toReservation_form.js）
        ↓
③ 日時をURLパラメーターに乗せて予約フォームへ遷移
        ↓
④ 予約フォームページが読み込まれる（turbo:load）
        ↓
⑤ seats_index.js がURLから日時を取り出す
        ↓
⑥ flatpickr が defaultDate として日時を受け取り画面に表示する
```

---

## ① 間取り図ページで日時を選択（flatpickr）

`seats_index.js` が `date-input` にflatpickrを取り付けている。

ユーザーがカレンダーで `2026-05-17 14:30` を選ぶと、flatpickrが `date-input` の値を更新する。

```
date-input の value = "2026-05-17 14:30〜"
```

---

## ② 「予約する」ボタンを押す（toReservation_form.js）

`toReservation_form.js` の中でボタンのクリックを検知して、`date-input` の値を読み取る。

```javascript
const startTime = document.getElementById('date-input').value;
// → "2026-05-17 14:30〜"
```

---

## ③ 日時をURLパラメーターに乗せて遷移

取り出した日時をURLの `?start_time=` に付けて、予約フォームページへ画面遷移する。

```javascript
const url = `/stores/1/seats/5/reservations/new`;
window.location.href = `${url}?start_time=${encodeURIComponent(startTime)}`;
```

実際に遷移するURL：

```
/stores/1/seats/5/reservations/new?start_time=2026-05-17%2014%3A30%E3%80%9C
                                   ↑ encodeURIComponent でエンコードされている
```

---

## ④ 予約フォームページが読み込まれる（turbo:load）

予約フォームページ（`reservations/new.html.erb`）が表示され、`seats_index.js` が再び動き出す。

`turbo:load` イベントが発火し、以下の処理が始まる。

---

## ⑤ seats_index.js がURLから日時を取り出す

```javascript
// 'reservation-date-input' → 予約フォームページが持つID
const dateInput = document.getElementById('reservation-date-input');

// URLの ?start_time= を読み取る
const urlParams = new URLSearchParams(window.location.search);
const startTimeParam = urlParams.get('start_time');
// → "2026-05-17 14:30〜"

// 「〜」を除いてDateオブジェクトに変換し、defaultDateVal に入れる
const parsed = new Date(startTimeParam.replace('〜', ''));
// → "2026-05-17 14:30" → Dateオブジェクト

defaultDateVal = parsed;  // ← これが flatpickr に渡る初期値
```

---

## ⑥ flatpickr が画面に日時を表示する

`defaultDate` に `defaultDateVal` を渡してflatpickrを初期化する。

```javascript
flatpickr(dateInput, {
  defaultDate: defaultDateVal,   // ← 2026-05-17 14:30 が入っている
  altInput: true,                // 表示用のinputを別途生成する
  altFormat: "Y年m月d日 H:i〜",  // 表示用の形式
  ...
});
```

`altInput: true` があるので、flatpickrは**画面表示用のinputを自動生成**して、そこに `altFormat` の形式で日時を表示する。

```
画面に表示される内容：「2026年05月17日 14:30〜」
```

---

## まとめ

| ステップ | 担当 | やっていること |
|---|---|---|
| ① 日時を選ぶ | flatpickr | `date-input` の value を更新 |
| ② ボタンクリック | `toReservation_form.js` | `date-input` の値を読み取る |
| ③ URL遷移 | `toReservation_form.js` | `?start_time=...` をURLに付けて画面遷移 |
| ④ ページ読み込み | ブラウザ / Turbo | 予約フォームページを読み込む |
| ⑤ URL解析 | `seats_index.js` | URLから日時を取り出して `defaultDateVal` に入れる |
| ⑥ 日時表示 | flatpickr | `defaultDate` を受け取って表示用inputに表示 |

日時はJavaScriptの変数やサーバーを経由せず、**URLパラメーター（`?start_time=`）** だけを媒介にして2つの画面をまたいでいる。
