# 予約確認画面: 選択座席のグレイアウト表示の仕組み

## 目的

予約確認画面では、ユーザーが選択した座席を間取り図上で視覚的に示しつつ、他の座席は選択できないようにする必要がある。

## 実装方法：3つの技術の連携

この機能は、Rails(View)、JavaScript、CSSの3者がそれぞれ役割を分担することで実現している。

### 1. Rails (View): HTMLへの情報埋め込み

まず、コントローラーから渡された選択座席の情報 (`@seat`) を、`confirm.html.erb` がHTMLの **data属性** を使ってページに埋め込む。

```erb
<%# app/views/reservations/confirm.html.erb %>
<div id="confirmed-seat" data-seat-number="<%= @seat.seat_number %>"></div>
```

これにより、ページのソースコード内に、選択された座席番号（例: "A-1"）の情報が保持される。

### 2. JavaScript: DOM操作によるロジック実行

「confirm.html.erb」ページ読み込み時には `reservation_confirm.js` が実行される。

```javascript
function confirmSeat() {
    const selectedSeat = document.getElementById('confirmed-seat');
    if (!selectedSeat) return;

    const seatNumber = selectedSeat.dataset.seatNumber;

    const radios = document.querySelectorAll('input[name="seat_id"]');
    radios.forEach(function(radio) {
        radio.disabled = true; // すべてのラジオボタンを一旦無効化

        if (radio.value === seatNumber) {
            radio.checked = true; // 該当する座席を選択状態にする
        }
    });

}
```

1.  `data-seat-number` 属性から、埋め込まれた座席番号を読み取る。
2.  `querySelectorAll` で、間取り図上の**全ての**座席ラジオボタンを取得する。
3.  `forEach` ループで、全てのラジオボタンに対して以下の処理を行う。
    -   まず、全てのボタンを `disabled = true` にして選択不可にする。
    -   もしボタンの `value` が、手順1で読み取った座席番号と一致すれば、そのボタンを `checked = true` にして選択状態にする。

### 3. CSS: `:checked` 状態に応じたスタイリング

最後に、JavaScriptによって特定のラジオボタンが `checked` 状態にされると、事前に定義されたCSSが適用される。

```css
.seat-radio:checked + .seat-box {
  background-color: #78350f; /* 選択色 */
}
```

`:checked` 擬似クラスと隣接兄弟セレクタ (`+`) を使うことで、チェックされたラジオボタンの隣にある座席の見た目 (`.seat-box`) の背景色を変更し、ハイライト表示を実現している。

## まとめ

- **Rails (View)**: サーバーサイドの情報をフロントエンドに渡す（データ埋め込み）
- **JavaScript**: 埋め込まれたデータを元に、ロジックを実行しDOMの状態を操作する（状態変更）
- **CSS**: DOMの状態（`:checked`）に応じて、見た目を変更する（スタイリング）

この役割分担により、それぞれの技術が得意な処理に集中でき、クリーンでメンテナンス性の高い実装となっている。
