# 解説：予約済み座席の無効化ロジック - 面接対策   260630

間取り図の各座席に書かれている、このコード。

```erb
<% reserved = @reserved_seat_numbers&.include?('C-1') %>
<label class="seat-label rondo-seat-c1 <%= 'disabled' if reserved %>">
  <input type="radio" name="seat_id" value="C-1" class="seat-radio" <%= 'disabled' if reserved %>>
  ...
</label>
```

これは、このアプリケーションの核となる「ダブルブッキング防止機能」を実現している部分であり、あなたの技術力をアピールする絶好のチャンスです。

この機能は、Webアプリケーション開発における以下の重要な要素をすべて含んでいるからです。

1.  **バックエンドの処理:** コントローラーがデータベースから必要な情報を取得する。
2.  **フロントエンドへのデータ連携:** コントローラーからビューへインスタンス変数を渡す。
3.  **動的なビューの生成:** ビューが受け取ったデータに応じて、HTMLの見た目や属性を変化させる。
