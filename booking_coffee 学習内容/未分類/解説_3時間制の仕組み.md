# 解説：3時間制の仕組み

## このカフェの予約ルール

予約は **3時間制**。13:00に予約したら、13:00〜16:00まで席を使う。

---

## 「席が空いているか」をどう判定するか？

ユーザーが「15:00から予約したい」と選んだとき、システムは **「15:00の時点でその席を使っている人がいるか」** を調べなければならない。

---

## なぜ「3時間引く」のか？

15:00に「使用中」となる予約は、**12:00〜15:00の間に開始した予約**。

なぜなら：
- 12:01に開始 → 12:01〜15:01まで使用 → **15:00時点でまだ使用中 → NG**
- 12:00ちょうどに開始 → 12:00〜15:00まで使用 → **15:00にちょうど終わる → OK（次の人が使える）**
- 11:59に開始 → 11:59〜14:59まで使用 → **15:00には終わっている → OK**

つまり「15:00に使用中の予約 = 12:00より後に始まり、15:00以前に始まった予約」

```
開始時刻の条件： (15:00 - 3時間) < start_time <= 15:00
             = 12:00 < start_time <= 15:00
```

---

## コードに直すと

```ruby
start_time = 15:00（ユーザーが選んだ時刻）

.where("reservations.start_time > ? AND reservations.start_time <= ?",
       start_time - 3.hours,   # = 12:00（この時刻より後）
       start_time)              # = 15:00（この時刻以前）
```

- `>` を使う理由：ちょうど12:00開始の予約は15:00に終わるので、次の予約を入れられる
- `<=` を使う理由：ちょうど15:00開始の予約は使用中になるのでNG

---

## まとめ

「3時間を足す」のは予約者が終了時刻を知るため（未来を見る）。
「3時間を引く」のはシステムが空席を探すため（過去を振り返る）。
