# 解説：enumの便利な機能 - 整数に意味のある名前を付ける

`enum`（イーナム）は、データベースに保存されている単なる整数（例: 0, 1, 2）に、プログラム上で意味のある名前（例: :reserved, :using, :checked_out）を関連付けるためのRailsの機能です。

これにより、コードの可読性が劇的に向上し、バグが起こりにくくなります。

---

## 1. やること：モデルに`enum`を定義する

`Reservation`モデルに、`status`カラムがどの整数とどの状態に対応するのかを定義します。

```ruby
# app/models/reservation.rb

class Reservation < ApplicationRecord
  # ... 他のコード ...

  enum status: { reserved: 0, using: 1, checked_out: 2 }

  # ... 他のコード ...
end
```

`status:`カラムの値が `0` なら「予約済み（:reserved）」、`1` なら「利用中（:using）」、`2` なら「チェックアウト済み（:checked_out）」である、とRailsに教えています。

---

## 2. なぜDBには整数で保存するのか？

データベースには `"reserved"` のような文字列ではなく、`0` のような整数で保存する方が、以下の点で有利だからです。

-   **パフォーマンス**: 文字列よりも整数の方が、検索や並び替え（インデックス）が高速です。
-   **データサイズ**: 文字列よりも整数の方が、データベースの容量を節約できます。

`enum`は、データベースの効率性とコードの分かりやすさを両立させるための、優れた設計思想です。

---

## 3. `enum`が提供する魔法のメソッド

`enum`を定義するだけで、Railsは以下のような便利なメソッドを自動的に追加してくれます。

| メソッドの例 | 意味 |
| :--- | :--- |
| `reservation.reserved?` | その予約のステータスは「予約済み」ですか？ (true/falseを返す) |
| `reservation.using?` | その予約のステータスは「利用中」ですか？ (true/falseを返す) |
| `reservation.reserved!` | その予約のステータスを「予約済み」に更新して保存します。 |
| `Reservation.reserved` | ステータスが「予約済み」の予約をすべて取得します。（スコープ） |
| `reservation.status` | `"reserved"` のように、現在のステータスを文字列で返します。 |

これらのメソッドを使うことで、「もし `reservation.status == 0` なら...」のような、意味が分かりにくい「マジックナンバー」をコードから排除できます。
