# 解説：選んだ日時を次のページに引き継ぐ方法 - URLパラメータの魔法

「間取り図で選んだ日時を、予約フォームのカレンダーに自動でセットしておきたい！」

この便利な機能を実現するために、一見すると少し不思議な方法で「日時」の情報をページからページへと引き継いでいます。

その核心は**URLパラメータ**と**JavaScriptファイルの再利用**にあります。

---

## 課題：ページを移動するとJavaScriptの情報は消える

Webページでは、リンクをクリックして別のページに移動すると、前のページでJavaScriptが持っていた変数などの情報はすべて消えてしまいます。

-   **間取り図ページ**でユーザーが「14:30」を選んだ。
-   「予約する」ボタンを押して**予約フォームページ**に移動した。
-   予約フォームページ側は、前のページで何時が選ばれたかを知るすべがない。

このままでは、ユーザーはもう一度「14:30」を選び直さなければならず、不便です。

## 解決策：URLに「置き手紙」を残す

そこで使うのが**URLパラメータ**です。これは、URLの末尾に `?キー=値` という形で情報を付け足して、次のページに情報を伝える古典的で強力なテクニックです。

まるで、次のページに移動する人に「この時間でよろしく！」と書いた置き手紙（URLパラメータ）を渡すようなイメージです。

```
https://.../reservations/new?start_time=2026-06-09%2014:30
                            ~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~
                            ↑ これが「置き手紙」
```

---

## 情報引き継ぎの2ステップ

この「置き手紙」作戦は、2つのステップで実現されています。

### ステップ1：置き手紙を書いて渡す（`toReservation_form.js`）

**場所：** 間取り図ページ (`stores/show`)

ユーザーが間取り図で座席を選び、「予約する」ボタンを押した瞬間に `toReservation_form.js` が動きます。

**仕事内容：**
1.  まず、今いる間取り図ページのURLをチェックします。
    （例: `.../stores/21?start_time=2026-06-09%2014:30`）
2.  URLの中から `?start_time=...` の部分（置き手紙）を見つけます。
3.  次に移動する「予約フォームページ」のURLの末尾に、その置き手紙を**そのままくっつけて**ジャンプさせます。

```javascript
// toReservation_form.js の仕事のイメージ

// 1. 今のページのURLから ?start_time=... を取り出す
const startTime = "2026-06-09 14:30"; 

// 2. 次のページのURLを作る
const nextUrl = "/stores/21/seats/A-1/reservations/new";

// 3. URLの末尾にくっつけて、そこに移動する！
window.location.href = `${nextUrl}?start_time=${startTime}`;
```

### ステップ2：置き手紙を読む（`seats_index.js`）

**場所：** 予約フォームページ (`reservations/new`)

**ここが最大のポイントです。**
この `seats_index.js` というファイルは、もともとトップページ（`stores/index`）や間取り図ページ用に作られたものですが、実は**予約フォームページでも読み込まれるように設定されています。**

そのため、予約フォームページが表示されたときにも `seats_index.js` は元気に動き出します。

**仕事内容：**
1.  まず、今いる予約フォームページのURLをチェックします。
    （例: `.../new?start_time=2026-06-09%2014:30`）
2.  URLの中から `?start_time=...` の部分（渡された置き手紙）を見つけ、その値を取り出します。
3.  `flatpickr`（カレンダー）の初期設定 `defaultDate` に、取り出した日時をセットします。

```javascript
// seats_index.js の仕事のイメージ

// 1. 今のページのURLから ?start_time=... を取り出す
const urlParams = new URLSearchParams(window.location.search);
const startTimeParam = urlParams.get('start_time'); // "2026-06-09 14:30" が取れる

// 2. flatpickrに「最初の値はこれだよ」と教える
flatpickr(".reservation-date-input", {
  defaultDate: startTimeParam // ここにセット！
});
```

### 結論

「間取り図ページでURLに日時をセット」→「予約ボタンでそのURLごと次のページへ」→「次のページで同じJSがURLを読んでカレンダーにセット」

この流れによって、`reservations/new.html.erb` のHTMLファイルを一切変更することなく、日時の自動入力が実現できているのです。

一つのJavaScriptファイルを複数のページで賢く再利用する、効率的な実装例と言えます。
