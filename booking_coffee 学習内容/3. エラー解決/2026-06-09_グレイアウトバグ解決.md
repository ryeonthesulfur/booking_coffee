# バグ解決：予約済み座席のグレイアウトが機能しない

## 発生日
2026-06-09

## 症状
間取り図ページで日時を選択してリロードしても、予約済みの座席が常にグレイアウトされる（日時に関係なく全部グレイか、全部グレイでないかになる）。

---

## 原因①：pluckが配列を返していた

### 問題のコード
```ruby
@reserved_seat_numbers = @store.seats
  .joins(:reservations)
  .where(reservations: { status: [:reserved, :using] })
  .pluck(:seat_number, :start_time)
```

`.pluck(:seat_number, :start_time)` のように複数カラムを指定すると、返り値が以下のような **配列の配列** になる。

```ruby
# 返ってくる値の例
[["A-1", 2026-06-09 14:00:00], ["B-2", 2026-06-09 17:30:00]]
```

ビュー側では `@reserved_seat_numbers.include?(seat.seat_number)` で比較しているが、配列の配列に対してseat_numberの文字列が一致することはないため、**常にfalseになる**。

### 修正後
```ruby
.pluck(:seat_number)
# 返ってくる値の例：["A-1", "B-2"]
```

---

## 原因②：start_timeがwhere句に渡されていなかった

### 問題のコード
```ruby
if params[:start_time].present?
  start_time = Time.zone.parse(params[:start_time].delete("〜"))
  @reserved_seat_numbers = @store.seats
    .joins(:reservations)
    .where(reservations: { status: [:reserved, :using] })
    .pluck(:seat_number)
end
```

`start_time` を変数にパースしているのに、where句に時間範囲の条件が書かれていなかった。そのため、**全ての予約済み座席**が日時に関係なくグレイアウトされていた。

### 修正後
```ruby
if params[:start_time].present?
  start_time = Time.zone.parse(params[:start_time].delete("〜"))
  @reserved_seat_numbers = @store.seats
    .joins(:reservations)
    .where(reservations: { status: [:reserved, :using] })
    .where("reservations.start_time > ? AND reservations.start_time <= ?", start_time - 3.hours, start_time)
    .pluck(:seat_number)
end
```
