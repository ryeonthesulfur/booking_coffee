  ↓ has_many

  ↑ belongs_to

## モデルの関連付けと主なバリデーション

### Store
```ruby
has_many :seats, dependent: :destroy
validates :name,      presence: true
validates :image_url, presence: true
validates :smoking,   inclusion: { in: [true, false] }
```

### Seat
```ruby
belongs_to :store
has_many :reservations
validates :seat_number,    presence: true
validates :seat_type,      presence: true
validates :capacity,       presence: true, numericality: { only_integer: true, greater_than: 0 }
validates :price_per_hour, presence: true, numericality: { greater_than_or_equal_to: 0 }
```

### Reservation
```ruby
belongs_to :user
belongs_to :seat
validates :start_time,   presence: true
validates :num_people,   presence: true, numericality: { only_integer: true, greater_than: 0 }
validates :phone_number, presence: true, format: { with: /\A\d{10,11}\z/ }
```

### User
```ruby
has_many :reservations
validates :name, presence: true
# その他は Devise が管理
```
